단말기 로그인 시 자동으로 각 매장에 적용됩니다. 미입력 시 카드결제가 불가합니다.

단말기 시리얼 번호

단말기에서 로그인하면 자동으로 등록됩니다. 직접 입력도 가능합니다.

연결 방법 안내

1

토스 단말기에서 오더앤고 앱 실행

토스 단말기의 홈 화면에서 오더앤고 플러그인 앱을 실행합니다.

2

매장 아이디 입력

왼쪽에 표시된 매장 아이디를 단말기 앱의 로그인 화면에 입력합니다.

3

비밀번호 입력

매장 계정 비밀번호를 입력합니다.

4

연결 완료 확인

로그인 성공 시 단말기 시리얼 번호가 자동으로 등록되고,
왼쪽 상단의 상태가 연결됨으로 변경됩니다.

5

결제 사용

POS 화면에서 카드결제 버튼을 누르면 단말기로 결제 요청이 전송됩니다.
