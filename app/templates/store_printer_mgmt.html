프린터 연결

미연결
연결된 프린터
프린터가 연결되지 않았습니다
통신 속도 (Baud Rate) ※ 출력이 안 되면 9600으로 변경 후 재연결
현재 브라우저는 USB 직접 연결을 지원하지 않습니다.
Chrome 또는 Edge 브라우저를 사용해주세요.
USB 직접 연결은 HTTPS 환경에서만 동작합니다.
처음 연결 시 Chrome의 포트 선택 창이 열립니다. 프린터가 목록에 보이지 않으면 USB 케이블 재연결 후 시도해주세요.

프린터 연결 방법

사전 준비

A

USB 케이블 연결

POS Bank 프린터의 USB-B 포트에 케이블을 연결하고, 반대쪽 USB-A를 포스 기기(PC/태블릿)에 연결합니다.
프린터 전원을 켜고 준비(READY) 상태를 확인합니다.

B

Chrome 브라우저 사용

USB 직접 연결은 Google Chrome 89 이상 또는 Edge에서만 지원됩니다.
현재 브라우저가 Chrome인지 확인해주세요.

연결 순서

1

"프린터 연결" 버튼 클릭

왼쪽 하단의 프린터 연결 버튼을 클릭하면 Chrome의 직렬 포트 선택 창이 열립니다.

2

목록에서 프린터 선택

팝업 목록에서 POS Bank 프린터를 선택하고 연결을 클릭합니다.
목록이 비어 있으면 USB 재연결 후 다시 시도해주세요.

3

테스트 출력으로 확인

연결 성공 후 테스트 출력 버튼을 눌러 프린터가 정상 동작하는지 확인합니다.
글자가 깨지면 Baud Rate를 9600으로 변경 후 재연결해주세요.

4

이후 자동 연결

한 번 연결 허가를 하면, 이후 POS 메뉴 화면에서 자동으로 재연결됩니다.
주문하기 클릭 시 자동으로 주문 슬립이 출력됩니다.
